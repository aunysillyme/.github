# Contributing

## What helps most

- **Bugs:** describe what happened and include the steps to reproduce it.
- **Ideas:** lead with the problem and the smallest useful change.
- **Pull requests:** keep the change small and focused.

Search open and closed issues before opening a new one. Use the matching issue form.
Reports and changes are reproduced before they are acted on.
Send security reports through [SECURITY.md](https://github.com/aunysillyme/.github/blob/main/SECURITY.md).

## Open a pull request

- **Scope:** make one change per pull request.
- **Run:** follow the repository's README to run the project and its checks.
- **Test:** say how you tested the change and what happened.
- **Context:** explain the problem and link the related issue, if there is one.

Contributions are offered under the repository's own license.

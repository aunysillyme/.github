# Security

## Report privately

Open the affected repository's Security tab. Where **Report a vulnerability** is available,
use it to open a private advisory for the maintainer to read.
Include the affected version, steps to reproduce the issue and its possible impact.
Keep credentials and personal data out of the report.

Where that option is unavailable, open an issue with only this title and body:

- **Title:** Private contact request
- **Body:** Please set up a private channel with me.

Keep every detail of the vulnerability out of the issue. The maintainer replies there to
arrange a private channel.

Credit goes in the release notes or changelog where the repository keeps them, unless you
ask otherwise.
